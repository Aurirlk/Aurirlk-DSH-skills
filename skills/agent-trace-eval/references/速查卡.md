# Agent Trace 评测 · 速查卡

> 做题 / 质检时只看这一张。

## 五步

```
1 读 Schema   → 必选/可选 · 参数形态 · 名不符实 · 返回值够不够 · 副作用
2 建台账     → C1…Cn，每条"可勾选的断言"
3 拆步骤     → S1…Sm
4 对矩阵     → 只记有 C 支撑的
5 定级理由   → 三句话 + 可执行修正
```

## 严重度（第一个"是"就停）

```
不可撤销副作用？ → 能撤销? Major : Critical
结果内容错？     → Major
只是形式？       → Minor
只是没必要？     → 不记
```

一句话：**要不要回滚？** 要 → Critical；要重做 → Major；改一下 → Minor。

## 五层分类

| 层 | 前缀 | 典型 |
|---|---|---|
| 意图 | `Intent-` | Misread / Overreach |
| 范围 | `Scope-` | Directory / Time / Type / Content / Source |
| 执行 | `Exec-` | Tool / Param / Capability / Dependency / Sequence |
| 副作用 | `Side-` | Premature / Wrong / Unauthorized |
| 输出 | `Out-` | Format / Completeness / Accuracy / Extra |

**一个行为一个主类型。**

## 八条铁律

1. **读取 ≠ 采纳**：范围内 + 读了 + 排除 = 对；纳入 = 错在"纳入"；范围外读了 = 错在"读"
2. **不必要 ≠ 违规**
3. **根因 ≠ 后果**：一条根因记一次
4. **报错 ≠ 静默成功**：后者更危险
5. **跑通 ≠ 用对**
6. **"不区分大小写"是放宽，不是跳过**
7. **包含 ≠ 开头**（`Re: [Atlas] X` 含但不以它开头）
8. **"确认后可做" ≠ "现在可以做"**

## 理由三句话

> ① 用户要求 **X**，Agent 做了 **Y**。
> ② 因为 **Z**，所以 **Critical/Major/Minor**。
> ③ 还触碰了 **C?**，次要不单列（或：独立错误另起 E2）。

## 约束台账格式

```
C{n}｜{原文要点 + 判定口径}｜{类型}
```

**检验：第三个人拿这条能独立判对错。**

## 三把尺子（找坑用）

- **边界**：`<` vs `<=`、`>` vs `>=`、一级 vs 递归、全部 vs 保留后
- **字符串**：完整短语 vs 分词、大小写、方括号、前缀
- **副作用**：读 / 写 / 半读半写（下载）
