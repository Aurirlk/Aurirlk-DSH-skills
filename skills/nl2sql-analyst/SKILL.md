# 自然语言问数（NL2SQL）

难点从来不是"生成 SQL"，是**查对表、守边界、说清口径、查不到别编**。

```
提问 → ①意图与上下文 → ②业务语义映射 → ③安全 SQL → ④执行 → ⑤校验与归因 → ⑥图表
```

## 一、意图总结与上下文绑定

从对话与系统上下文里抽出四个东西：

| 项 | 抽什么 | 缺了怎么办 |
|---|---|---|
| **作用域** | 租户 ID、基地/项目 ID | 缺一不可，直接问用户，不许猜 |
| **时间跨度** | "最近""这周"→ 标准日期区间 | 结合系统注入的当前时间换算，并回显 |
| **对象** | 具体点位 / 全部汇总 | 默认单点位，不默认全量 |
| **指标** | 用户真正想要的那个数 | 有歧义就列 2 个候选让用户选 |

**回显纪律**：算完时间区间要回显一次（"2026-11-13 至 2026-11-19"），让用户能在错误放大前纠正。

## 二、业务语义映射

**口语词 → 表字段 → 计算口径**，三者必须一次写清。

这是 NL2SQL 最容易出错的地方：用户说的词，在系统里可能对应**两张不同的表**。

### 映射表模板

| 用户说法 | 源表 | 字段与口径 | 禁忌 |
|---|---|---|---|
| 日投喂量 | `feeding_log` | `SUM(feed_weight)` 按日聚合 | **不从监控表取** |
| 转化率 | `feed_log` + `biomass` | `SUM(feed) / (end_b - start_b)` | 分母为 0 需保护 |
| 达成率 | `target` + `actual` | `actual / target * 100%` | 目标未设置时返回"无目标" |

**强制要求**：每个易混指标都要写明「**不要从哪张表取**」。光说"从哪里取"不够——模型会就近找一张有相关字段的表。

## 三、安全 SQL 四条铁律

### 1. 强制作用域隔离

所有 `SELECT`，**主表与所有关联表的 `WHERE` 都必须显式注入作用域条件**：

```sql
WHERE t.tenant_id = :tenant_id
  AND t.base_id = :base_id   -- 上下文指定了才注入
```

**跨租户查询是安全事故，不是 bug。** 这一条没有任何商量空间。

### 2. 只读

只允许 `SELECT`。禁止 `INSERT` / `UPDATE` / `DELETE` / `DROP` / `ALTER` / `TRUNCATE`。

**实现方式**：在工具层拦截，不要只靠 prompt 约束。prompt 会被绕过。

### 3. 除零与空值保护

```sql
-- 比率类一律加保护
SUM(a) / NULLIF(SUM(b), 0)
```

### 4. 参数化，不拼接

一律绑定参数，禁止字符串拼接用户输入。

## 四、结果校验与诚实原则

### 空数据

返回 0 行时：

- ✓「当前条件下暂无记录，请核对立项编号或确认数据是否已录入」
- ✗ 用"通常""一般""大约"编一个数

**这是最常被打破的一条**，也是用户最不能容忍的一条。

### 异常波动归因

查到结果后，如果数值明显异常（骤降、骤升、比率超常），**不要只报数字，要关联同期环境变量做解释**：

```
指标：转化率 2.8（历史区间 1.2–1.6）
同期：平均温度 12°C（历史同期 22°C），投入量未减
归因：低温导致效率下降，但投入未相应下调，故比率升高
```

**归因必须基于查到的数据**，不能凭常识编。

### 数据质量提示

必要时输出一条治理建议（"该点位近 3 天无填报记录，建议排查录入流程"）——**这比一个错数字有用得多**。

## 五、图表推荐

按数据维度选，不要按好看选。

| 数据特征 | 图表 |
|---|---|
| 单指标时间趋势 | 折线 `line` |
| 多对象横向对比 | 分组柱状 `bar` |
| 双指标关联（不同量纲） | 双轴组合 `combo` |
| 占比构成 | 饼图或堆叠柱（>6 类用堆叠柱） |
| 单值达成 | 仪表盘 / 进度条 |

**图表只是载体。结论要用一句话说清**，且这句话不能比数据更肯定。

## 六、输出结构

```markdown
## 查询条件
- 作用域：…… / 时间：2026-11-13 ~ 2026-11-19 / 对象：……

## 结果
| 维度 | 指标 | 数值 |
|---|---|---|

## 结论
一句话，尽量带上对比基线。

## 建议图表
类型 + 理由（一句）
```

## 七、常见失败

| 症状 | 根因 |
|---|---|
| 查到了别的租户的数据 | 关联表没注入作用域条件 |
| 数字对但口径错 | 语义映射没写"禁忌表" |
| 不存在的对象也返回了数 | 没有先校验对象存在性 |
| 查不到就编 | 空数据没有显式处理分支 |
| 比率偶尔报错 | 漏了 `NULLIF` |
| 图表花哨但没用 | 按好看选，不按维度选 |

## 八、自检

- [ ] 作用域（租户/基地）已绑定，未猜测
- [ ] 时间区间已换算并回显
- [ ] 每个指标写了源表 + 口径 + **禁忌表**
- [ ] 所有 SELECT 注入了作用域条件
- [ ] 只有只读语句
- [ ] 比率类字段有除零保护
- [ ] 空结果走诚实分支，未编造
- [ ] 异常值做了数据归因，不是只报数
- [ ] 图表类型与数据维度匹配
