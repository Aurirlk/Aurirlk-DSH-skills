# chibi-sticker-pro

> 本技能是 [Aurirlk DSH Skills](../../README.md) 合集的一员 · [← 返回仓库目录](../../README.md)

**中文** | [English](README.en.md)

资深 Q 版贴纸设计专家。把人物照片做成盲盒风的 4×3 共 12 宫格表情包，重点是**像本人**——脸型、发型、发际线这些骨相特征先映射，再谈可爱。

## 什么时候用

- 拿一张人物照片要做 Q 版头像、盲盒风贴纸、微信表情包
- 要一整套 12 种情绪，而不是一张图
- 图像模型出来的图"不像本人"或 12 格风格不统一

## 它做什么

1. **Deep Scan**：先在内心分析年龄气质、脸型几何（圆/方/心形）、颧骨下颌、发型质感与结构、眼镜痣胡须等关键锚点。
2. **12 宫格规划**：大笑/瀑布泪/冒火/瞳孔地震/爱心眼/墨镜歪嘴/脸红对戳/头顶问号/鼻涕泡 Zzz/星星眼/口罩黑线/撒花，12 个互不重复。
3. **出图或出指令**：白底 #FFFFFF、粗白描边、二头身、C4D 盲盒质感；不能直接出图时交付可复制的完整生成指令。

## 用法

```
把这张照片做成 12 宫格 Q 版表情包，保留他的方脸和卷发
```

```
帮我写一份盲盒风贴纸的生成指令，12 种情绪，白底粗描边
```

## 硬指标

12 个表情必须不同、排列整齐不粘连；无文字水印、无模糊噪点、无多余手指。加简体中文心情字时逐字核对字形——写错宁可不加。

## 边界

- 需要用户提供人物照片；没有照片只能按文字描述做通用形象。
- 涉及真人肖像时，请用户自己确认使用授权。
