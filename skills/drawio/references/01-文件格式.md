# draw.io 文件格式速查

`.drawio`（也叫 `.xml` / `.drawio.xml`）就是一个 XML 文件，外壳是 `mxfile`，里面每页一个 `diagram`，
每页的内容是一个 `mxGraphModel`。

**纯文本、可 diff、可程序化生成、可手写。** 这是它比 Visio 之类强的地方。

## 骨架

```xml
<mxfile host="app.diagrams.net" agent="DSH" type="device">
  <diagram id="arch" name="系统架构图">
    <mxGraphModel dx="1600" dy="1000" grid="1" gridSize="10" guides="1" tooltips="1"
                  connect="1" arrows="1" fold="1" page="1" pageScale="1"
                  pageWidth="1400" pageHeight="900" math="0" shadow="0">
      <root>
        <mxCell id="0" />
        <mxCell id="1" parent="0" />
        <!-- 这里放你的图形 -->
      </root>
    </mxGraphModel>
  </diagram>
</mxfile>
```

**`<mxCell id="0" />` 和 `<mxCell id="1" parent="0" />` 是必需的、固定不变的。**
它们是图层容器（layer）。你所有的图形都写在 `id="1"` 这个图层里——除了这两个，
其它 cell 一律不要用 id `0` 或 `1`。

### 多页

一个 `mxfile` 里可以有多个 `diagram`，每个是一页：

```xml
<mxfile>
  <diagram id="arch" name="系统架构图"><mxGraphModel>…</mxGraphModel></diagram>
  <diagram id="ui"   name="产品界面效果图"><mxGraphModel>…</mxGraphModel></diagram>
</mxfile>
```

- 页序 = `diagram` 出现顺序
- 导出时 `--page-index` **是 1-based**，`0` 会静默回落到第 1 页（详见 `02-CLI导出.md`）
- `name` 是给人看的页名，`id` 是给程序用的

## 两类 cell：顶点和边

### 顶点（图形）

```xml
<mxCell id="n13" value="Web 前端&#10;React + TS"
        style="rounded=1;whiteSpace=wrap;html=1;fillColor=#dae8fc;strokeColor=#6c8ebf;"
        vertex="1" parent="1">
  <mxGeometry x="190" y="105" width="220" height="70" as="geometry" />
</mxCell>
```

| 属性 | 说明 |
|---|---|
| `id` | 唯一标识，边用它来引用 |
| `value` | 显示的文字。**换行必须用 `&#10;`**，写字面换行会被 XML 折叠掉 |
| `style` | 分号分隔的键值对，见下 |
| `vertex="1"` | 标记这是图形 |
| `parent` | 父 cell 的 id。**绝大多数情况写 `1`** |
| `mxGeometry` | 位置和尺寸 |

### 边（连线）

```xml
<mxCell id="e0"
        style="edgeStyle=orthogonalEdgeStyle;rounded=1;endArrow=block;endFill=1;strokeColor=#64748b;strokeWidth=1.5;"
        edge="1" parent="1" source="n13" target="n17">
  <mxGeometry relative="1" as="geometry" />
</mxCell>
```

`source` / `target` 填顶点 id。边可以只有 `source` 或只有 `target`（此时要靠 `mxPoint` 定位）。

### 边的出入点与拐点

这条是治「连线穿框」的关键。

```xml
<!-- 指定出入边：0=左 0.5=中 1=右（exitX/entryX），同理 y -->
<mxCell id="e1" style="edgeStyle=orthogonalEdgeStyle;exitX=0.5;exitY=1;exitDx=0;exitDy=0;entryX=0.5;entryY=0;entryDx=0;entryDy=0;"
        edge="1" parent="1" source="a" target="b">
  <mxGeometry relative="1" as="geometry" />
</mxCell>
```

```xml
<!-- 显式拐点：让线绕开中间的方框 -->
<mxCell id="e2" style="edgeStyle=orthogonalEdgeStyle;" edge="1" parent="1" source="a" target="b">
  <mxGeometry relative="1" as="geometry">
    <Array as="points">
      <mxPoint x="120" y="560" />
      <mxPoint x="900" y="560" />
    </Array>
  </mxGeometry>
</mxCell>
```

## 坐标系统

**这是最容易搞错的地方。**

`mxGeometry` 的 x/y 是**相对父 cell 的**：

- `parent="1"` → 相对画布左上角 `(0,0)`。**这是你想要的。**
- `parent="某个分层容器"` → 相对那个容器的左上角。算起来容易出错，而且容器一移动，
  里面的东西跟着动，看起来很美好，实际改起来很痛苦。

**本项目采用的约定：所有顶点和边都挂 `parent="1"`，分层容器只当装饰性的虚线框。**

这样坐标永远是画布绝对坐标，一眼能算，程序化生成也简单。代价是移动容器时里面的方框不会跟着动——
但生成场景下你本来就要重算坐标。

## 常用样式（style）

style 是一个分号分隔的字符串，末尾那个分号是习惯，可省。

### 通用

| 键 | 值 | 作用 |
|---|---|---|
| `fillColor` | `#dae8fc` / `none` | 填充色 |
| `strokeColor` | `#6c8ebf` / `none` | 边框色 |
| `fontColor` | `#0f172a` | 字色 |
| `fontSize` | `13` | 字号 |
| `fontStyle` | `0` 常规 / `1` 粗体 / `2` 斜体 / `4` 下划线 | 可相加 |
| `rounded` | `1` | 圆角 |
| `arcSize` | `8` | 圆角半径（百分比） |
| `dashed` | `1` | 虚线边框 |
| `dashPattern` | `8 4` | 虚线段长 |
| `align` | `left`/`center`/`right` | 水平对齐 |
| `verticalAlign` | `top`/`middle`/`bottom` | 垂直对齐 |
| `whiteSpace` | `wrap` | 允许自动换行 |
| `html` | `1` | 允许 HTML 实体 |
| `horizontal` | `0` | 文字旋转 90°（做竖排层名用） |

### 分层容器（虚线框）

```xml
style="rounded=1;arcSize=4;fillColor=none;strokeColor=#cbd5e1;dashed=1;dashPattern=8 4;"
```

### 纯文字标签（无边框无填充）

```xml
style="text;html=1;align=left;verticalAlign=middle;fillColor=none;strokeColor=none;overflow=visible;fontSize=24;fontStyle=1;"
```

`overflow=visible` 让文字超出框也不被裁掉——标题类文字该加。

### 纯文字标签 vs 方框的区别

`text;` 开头的 style 是「无形状的文字」，体检脚本会把它排除在「方框重叠」检查之外，
因为标题、层名这类标签本来就会压在别的元素附近。**想让体检结果干净，纯标签请务必用 `text;`。**

### 经典配色（draw.io 内置色板）

| 语义 | fillColor | strokeColor |
|---|---|---|
| 蓝（前端/入口） | `#dae8fc` | `#6c8ebf` |
| 绿（网关/中间） | `#d5e8d4` | `#82b366` |
| 橙（业务服务） | `#ffe6cc` | `#d79b00` |
| 紫（中间件） | `#e1d5e7` | `#9673a6` |
| 红（数据层） | `#f8cecc` | `#b85450` |
| 灰底（面板） | `#f8fafc` | `#e2e8f0` |
| 深色（顶栏） | `#111827` | `#111827` |

这套色板的好处是**在浅色和深色主题下都还看得清**，而且辨识度高。

## 压缩格式

draw.io 保存时可能把 `mxGraphModel` 压缩掉，此时 `<diagram>` 的内容是一串 base64 而不是嵌套的 XML：

```xml
<diagram id="arch" name="系统架构图">7Vpbc9o4FP41zLQP7YBkG …(很长的一串)… </diagram>
```

编码方式是 **base64 → raw deflate → URL 编码（`encodeURIComponent`）**，解码就是反过来：

```
base64 解码 → DeflateStream 解压 → Uri.UnescapeDataString
```

`scripts/Test-DrawioLayout.ps1` 会自动识别并解开这种格式，所以你不需要手动转换。
但**手写生成时请用未压缩格式**（就是本文上面那种嵌套 XML），可读、可 diff、出问题好查。

## 自己写一个最小可用的 .drawio

```xml
<mxfile host="app.diagrams.net" agent="DSH" type="device">
  <diagram id="p1" name="示例">
    <mxGraphModel dx="800" dy="600" grid="1" gridSize="10" page="1" pageScale="1"
                  pageWidth="850" pageHeight="1100" math="0" shadow="0">
      <root>
        <mxCell id="0" />
        <mxCell id="1" parent="0" />
        <mxCell id="a" value="开始" style="rounded=1;fillColor=#dae8fc;strokeColor=#6c8ebf;"
                vertex="1" parent="1">
          <mxGeometry x="80" y="80" width="160" height="60" as="geometry" />
        </mxCell>
        <mxCell id="b" value="结束" style="rounded=1;fillColor=#d5e8d4;strokeColor=#82b366;"
                vertex="1" parent="1">
          <mxGeometry x="80" y="240" width="160" height="60" as="geometry" />
        </mxCell>
        <mxCell id="e1" style="edgeStyle=orthogonalEdgeStyle;endArrow=block;endFill=1;"
                edge="1" parent="1" source="a" target="b">
          <mxGeometry relative="1" as="geometry" />
        </mxCell>
      </root>
    </mxGraphModel>
  </diagram>
</mxfile>
```

存成 UTF-8，用 `Export-Drawio.ps1` 导一下就知道对不对了。
