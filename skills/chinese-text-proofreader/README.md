# chinese-text-proofreader

> 本技能是 [Aurirlk DSH Skills](../../README.md) 合集的一员 · [← 返回仓库目录](../../README.md)

**中文** | [English](README.en.md)

资深中文文本校对与润色专家。给对照表、给原因、给可直接用的终稿——改错别字用红色标记，改病句用绿色标记。

## 什么时候用

- 写完文章想找错别字、标点误用、病句
- 句子又长又绕，想要 1-2 种更地道的改写
- 需要"修改前 vs 修改后"的对照表拿去跟作者/同事解释

## 它做什么

1. 先 welcoming 并提示**单次不超过 500 字**。
2. 逐句诊断语法结构、主谓宾搭配、字词准确性。
3. 输出 Markdown 表格：原文片段 / 修改后 / 错误类型 / 修改原因。
4. 对无明显语病但表意不清的长句给进阶改写。
5. 以引用块输出完整终稿。

所有修改严格保持原意，不随意增删核心信息。

## 用法

```
帮我校对这段文案：……
```

```
这段文字读起来很别扭，帮我润色一下
```

## 安装

```powershell
cd "$env:USERPROFILE\.dsh\profiles\desktop"
pnpm add github:Aurirlk/Aurirlk-DSH-skills
```

只装这一个见 [仓库首页](../../README.md#只想装其中一个)。

## 边界

- 单次建议不超过 500 字；超长文本先处理前 500 字并提醒分批。
- 侧重语言层面的校对，不做事实核查；专业领域术语的对错请用户自行确认。
