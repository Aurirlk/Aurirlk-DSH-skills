# 视觉场景判别

单帧看特征，序列看趋势，结论看边界。

**核心命题**：图像判别出错，八成不是模型看错了，是**没先说清自己能看到什么**。

## 什么时候用

- 监控画面 → 行为/状态/风险判定
- 视频抽帧序列 → 演进阶段判定
- 无标注基准、画面质量受限、误判代价高

**不适用**：有明确类别标签的标准图像分类任务。

## 一、输入解析

判之前先把手里的东西拆干净。

| 项 | 处理 |
|---|---|
| **图像数量** | 单帧 / 序列 / 视频抽帧。序列要记录帧间间隔 |
| **时间戳** | 优先从文件名或元数据解析，**原样引用，不换算时区**。无则用系统时间并注明"系统注入" |
| **业务上下文** | 点位编号、对象身份、设备状态、传感器读数——**传入了就原样采信** |
| **干扰过滤** | 剔除用户消息里夹带的系统标签、路由字段、乱码 |

**标识符纪律**：上下文没给编号，就统一写"当前监控对象"。**不许编一个像真的。**

## 二、先声明光学与分辨率边界

这是整个框架与"瞎猜"的分界线。

| 边界类型 | 要声明什么 |
|---|---|
| 距离 | 远距离水面俯视 → 看不清个体细节，只能判群体行为 |
| 光照 | 夜间/红外 → 失去色彩信息，纹理判据失效 |
| 遮挡 | 水面反光、雨雾 → 部分区域不可判 |
| 帧率 | 抽帧间隔大 → 无法判瞬时动作，只能判趋势 |
| 分辨率 | 低于某阈值 → 不可判微小特征 |

**声明方式**：「本次依据为远距离俯视监控，无法辨认个体体表细节，以下结论仅基于群体动线与水面扰动。」

说完这句，后面所有结论的可信度就自动被限定了——**这是保护，不是免责。**

## 三、用多维不变量，不用单点特征

单点特征最容易误判。**至少四个互相独立的维度同时成立，才下结论。**

以"群体活动状态"为例，可迁移的四维：

| 维度 | 看什么 |
|---|---|
| **趋向性** | 运动有没有明确目标指向；朝中心汇聚还是朝边界离散 |
| **一致性** | 群体是同向列队，还是个体各自乱走、离群独行 |
| **时间梯度** | 强度是平滑起落（由弱到强再衰减），还是瞬间突变 |
| **残留动态** | 目标对象（投入物/物料/人员）的消耗与滞留节奏 |

**判定规则**：四个维度互相冲突时，**不要投票，要报告冲突**。

> 「趋向性显示主动靠近，但一致性出现离群个体，两者矛盾，倾向判为局部异常而非整体状态改变。」

**报告冲突比强行统一更有价值。**

## 四、时间梯度判别（序列特有）

单帧只能定性，序列才能判**阶段**。

| 阶段 | 判据 |
|---|---|
| 起始 | 从静止转入活动，强度低，指向性弱 |
| 峰值 | 强度高、一致性强、目标指向明确 |
| 衰减 | 强度下降，个体开始离散，指向性消失 |
| 终止 | 回到静止或转为其他活动模式 |

**关键判据是"形状"，不是"绝对值"。** 平滑下降 = 自然结束；瞬间消失 = 外部干扰。

这一条极其通用：
- 平滑衰减 → 正常完成
- 断崖式中断 → 外力介入
- 平台期过长 → 异常滞留
- 反复起落 → 循环故障

## 五、鉴别诊断：给每个高危误判配一个可观测鉴别点

这是本框架最有价值的一节。

**做法**：列出这类场景里最容易被误判的 N 种情况，每种写一行——"看起来像 X，但如果是 Y，你会同时看到 Z"。

| 表面现象 | 常见误判 | 可观测鉴别点 |
|---|---|---|
| 群体剧烈翻动 | 判为"异常暴动" | 向心聚集 = 正常高强度作业；离心四散 = 受惊 |
| 表面平静无活动 | 判为"空无一人/无对象" | 检查是否有零星单点扰动；低频不等于没有 |
| 强度突然下降 | 判为"系统故障" | 是否有外部输入变化；平滑下降多为正常结束 |
| 局部异常 | 判为"整体异常" | 离群个体占比；<5% 多为个体问题 |

**写作要求：鉴别点必须是可观测的。** "注意区分"不是鉴别点，"看它是向心还是离心"才是。

## 六、无基准时用相对梯度

如果画面没有历史基准、无法定绝对阈值，**一律改用相对变化**：

- ✗「水花高度 > 20cm 为高强度」← 没有标定就是瞎编
- ✓「与本次序列起始帧相比，扰动面积扩大到 3 倍以上」← 相对，可验证

**相对判据的两个纪律**：
1. 必须指明基准是什么（起始帧 / 同点位历史 / 相邻时段）
2. 不得把相对倍数换算成绝对物理量

## 七、分级与输出

### 风险分级

| 级别 | 判据 | 处置 |
|---|---|---|
| 高 | 直接危及安全，或证据链完整且后果不可逆 | 立即处置 + 通知 |
| 中 | 有明确异常信号，但证据不全或后果可恢复 | 观察 + 取证 |
| 低 | 疑似异常，需更多数据 | 记录 + 下次复查 |

**分级依据写出来。**「高」高在哪一句，要能指回去。

### 输出结构

```markdown
## 判定
- 边界声明：……
- 观察到的维度：趋向性 / 一致性 / 时间梯度 / 残留动态
- 结论：……（置信度：中）

## 鉴别
- 排除了：……（依据：……）
- 无法排除：……

## 建议
- 立即：……
- 后续：……
```

## 八、防幻觉五条

1. 看不清就写"无法辨认"，不要补全。
2. 不许从单帧推断长时间趋势。
3. 不许把"没有观察到"写成"不存在"——**两者差一个观测条件**。
4. 不许编造点位编号、时间、数量。
5. 结论必须能被"这张图里哪一块"支撑；支撑不了就降低置信度。

- [ ] 观察与推断分开写
- [ ] 至少四个独立维度，冲突时如实报告
- [ ] 有序列时做了时间梯度判别，不是只看单帧
- [ ] 每个高危误判都配了可观测鉴别点
- [ ] 无基准时用相对梯度，并指明基准
