# visual-scene-judge

> 本技能是 [Aurirlk DSH Skills](../../README.md) 合集的一员 · [← 返回仓库目录](../../README.md)

**中文** | [English](README.en.md)

监控画面场景判别的通用框架。

**核心命题：图像判别出错，八成不是模型看错了，是没先说清自己能看到什么。**

## 什么时候用

- 监控画面 → 行为 / 状态 / 风险判定
- 视频抽帧序列 → 演进阶段判定
- 无标注基准、画面质量受限、误判代价高

## 五层结构

```
1 输入解析     → 数量、时间戳、业务上下文、干扰过滤
2 边界声明     → 距离 / 光照 / 遮挡 / 帧率 / 分辨率
3 多维不变量   → 趋向性 / 一致性 / 时间梯度 / 残留动态
4 时间梯度     → 起始 → 峰值 → 衰减 → 终止
5 鉴别诊断     → 每个高危误判配一个可观测鉴别点
```

## 三个最关键的判断

### ① 先声明看不到什么

> 「本次依据为远距离俯视监控，无法辨认个体细节，以下结论仅基于群体动线与水面扰动。」

说完这句，后面所有结论的可信度自动被限定。**这是保护，不是免责。**

### ② 四个维度冲突时，报告冲突

**不要投票，不要强行统一。**

> 「趋向性显示主动靠近，但一致性出现离群个体，两者矛盾，倾向判为局部异常。」

**报告冲突比强行统一有价值。**

### ③ 鉴别的"形状"比"绝对值"重要

- 平滑衰减 → 正常结束
- 断崖式中断 → 外力介入
- 平台期过长 → 异常滞留
- 反复起落 → 循环故障

这条判据可以迁移到任何时序场景。

## 无基准时用相对梯度

没有历史基准就**不许定绝对阈值**：

- ✗ 「扰动高度 > 20cm 为高强度」
- ✓ 「与序列起始帧相比，扰动面积扩大 3 倍以上」

相对判据两纪律：必须指明基准；不许换算成绝对物理量。

## 防幻觉五条

1. 看不清就写"无法辨认"
2. 不许从单帧推断长趋势
3. **不许把"没观察到"写成"不存在"**——两者差一个观测条件
4. 不许编造编号、时间、数量
5. 结论必须能被"图里哪一块"支撑
