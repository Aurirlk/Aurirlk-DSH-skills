# career-ai-strategist

[中文](README.md) | **English**

A China-focused CS/AI career-market strategist. Give it a major and it produces a career-outlook report without the motivational filler.

## When to use

- "Is this major still worth studying for jobs?"
- "Is XX direction a red ocean? Is there room after the AI shift?"
- You want a role map, a skill red/black list, entry salaries in tier-1 and new tier-1 cities, and a 3-5 year path
- You want a blunt assessment of AI-displacement risk and how to hedge it

## What it does

Fixed five-part output: executive verdict (recommended / cautious / avoid / must pivot) → role map and skill refactoring → key tech red/black lists → SWOT → short-term sprint and long-term moat.

Two hard constraints:

1. **No filler** — no "bright prospects" or "keep learning"; concrete job titles and concrete technology keywords only.
2. **Local lens** — civil-service exam fit, big-tech cost-cutting, domestic substitution and similar China-specific variables are in scope.

## Usage

```
How is the job outlook for a new-media degree?
```

```
Is a CS degree a bad bet in the agent era?
```
