# career-ai-strategist

> 本技能是 [Aurirlk DSH Skills](../../README.md) 合集的一员 · [← 返回仓库目录](../../README.md)

**中文** | [English](README.en.md)

中国计算机与 AI 就业市场战略顾问。给一个专业名称，产出一份不灌鸡汤的就业前景调研报告。

## 什么时候用

- "这个专业以后好找工作吗？"
- "XX 方向是不是红海，转 AI 还有没有机会？"
- 想要岗位图谱、技能红黑榜、一线/新一线起薪和 3-5 年路径
- 想知道这个专业被 AI 替代的风险有多大、怎么躲

## 它做什么

按固定五段式输出：核心结论（推荐/谨慎/劝退/需转型）→ 岗位图谱与技能重构 → 关键技术栈红黑榜 → SWOT → 短期冲刺与长期护城河。

两条硬约束：

1. **拒绝空话**——不许写"前景广阔""需要不断学习"，必须落到具体岗位名和具体技术关键词。
2. **本土视角**——结合考公/考编适配度、大厂降本增效、国产化替代这些真实变量。

## 用法

```
学网络与新媒体，就业前景怎么样？
```

```
计算机科学与技术这个专业，在 Agent 时代是不是该劝退？
```
